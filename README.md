Grind Mode - Fitness Website

Grind Mode is a fitness-themed website that includes features like video tutorials, a navigation menu, a footer with contact and social links, trainers and bootcamps sections, and more. The website is styled with a modern, clean design to provide users with an engaging fitness experience.

Technologies Used
HTML: Used for structuring the content of the website.

CSS: Used for styling the website. It is responsive and follows a fitness-based theme.

JavaScript: Adds interactivity to the website, including:

Mobile navigation toggle

Smooth scrolling for anchor links

Scroll-based animations

Basic form validation

Google Fonts: Poppins and Montserrat for modern typography.

Features
Responsive Design: The site is fully responsive and adjusts for mobile and tablet viewports using media queries.

Mobile Navigation: A collapsible navigation menu that is revealed when the user clicks the menu button on mobile devices.

Smooth Scrolling: Anchor links on the website smoothly scroll to the relevant sections.

Scroll Animations: Elements are animated as the user scrolls down the page.

Form Validation: Basic form validation for the sign-up form to ensure all fields are filled out.

Interactive Services Section: Displays available fitness services, including trainers and bootcamps.

Footer with Social Links: A fixed footer with contact information and links to social media profiles.

File Descriptions
HTML Files
index.html: The homepage of Grind Mode, containing an overview of the website, links to other pages, and a video section.

services.html: A section that describes the services offered by Grind Mode, including trainers and bootcamps.

about.html: Information about the brand and mission of Grind Mode.

meals.html: A page dedicated to help the athletes track their eating habits.

equipments.html: A page dedicated to showcase the best gym equipments used during workouts.

signup.html: A sign-up form where users can join Grind Mode for updates.

tutorials.html: Entails some workout demonstrations to help the athlete better their technique.

login.html: A login form where members can join back Grind Mode.
CSS File
style.css: The main stylesheet that applies design and layout to the HTML elements. It contains:

Base styles (font family, color scheme)

Layout for headers, footers, navigation, and sections.

Responsive design for different screen sizes.

Animations (e.g., fade-in effects).

JavaScript File
script.js: This file handles all the interactivity of the website. Features include:

Mobile navigation toggle: The menu button reveals or hides the mobile menu.

Smooth scroll: Anchored links scroll smoothly to the respective sections.

Scroll animations: Elements fade in as the user scrolls.

Form validation: Ensures that form fields are filled out before submission.
